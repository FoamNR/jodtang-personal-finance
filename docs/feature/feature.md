# 📱 สรุปขอบเขตฟีเจอร์: แอปพลิเคชันจดตัง (Offline Expense Tracker)

**รูปแบบแอปพลิเคชัน:** ทำงานแบบ Offline 100% ประมวลผลและจัดเก็บข้อมูลภายในเครื่องด้วยฐานข้อมูล SQLite พร้อมระบบสำรองข้อมูลด้วยไฟล์ (`.csv` และ `.zip` / `.db`)

---

## 1. ระบบการจดบันทึกธุรกรรม (Transaction Management)
- **เพิ่ม/แก้ไข/ลบ รายการ:** บันทึกยอดเงิน เลือกประเภท (รายรับ `Income`, รายจ่าย `Expense`, โอนย้าย `Transfer`) ระบุวันที่/เวลา และบันทึกช่วยจำ (Note)
- **การแนบรูปสลิป/ใบเสร็จ (Image Attachment):**
  - เลือกรูปจากอัลบั้มหรือถ่ายภาพใบเสร็จ/สลิปโอนเงินแนบไปกับรายการบันทึกได้
  - คัดลอกและบีบอัดไฟล์รูปไปเก็บใน Local Storage เฉพาะของแอป (`ApplicationDocumentsDirectory`) และบันทึกเฉพาะชื่อไฟล์/Relative Path ลงในตาราง SQLite เพื่อไม่ให้ฐานข้อมูลบวม
  - กดดูรูปภาพขนาดเต็ม (Full-screen Preview) และลบหรือเปลี่ยนรูปแนบได้
- **โอนเงินระหว่างกระเป๋า (Transfer & Balance Validation):**
  - ย้ายยอดเงินจากกระเป๋าต้นทางไปยังกระเป๋าปลายทาง โดยไม่ถูกนำไปคำนวณรวมเป็นยอดรายรับหรือรายจ่ายของเดือน
  - **ระบบตรวจสอบยอดเงินต้นทาง:** บัญชีต้นทางต้องมียอดเงินคงเหลือเพียงพอสำหรับการโอน ไม่สามารถโอนเกินยอดที่มีได้ เพื่อป้องกันกระเป๋าเงินติดลบ
  - **การแจ้งเตือน Real-time:** แสดงเพดานที่โอนได้ `โอนได้สูงสุด ฿xx.xx` และเตือนตัวหนังสือสีแดงทันทีที่พิมพ์เกิน (`AutovalidateMode.onUserInteraction`)
  - **รองรับการแก้ไขรายการเดิม:** คำนวณคืนยอดเงินเดิมกลับเข้ากระเป๋าต้นทางก่อน ทำให้ผู้ใช้แก้ไขปรับยอดเงินได้อย่างอิสระและถูกต้อง
  - **ป้องกันการเลือกกระเป๋าซ้ำ:** ปิดไม่ให้เลือกกระเป๋าต้นทางในช่องกระเป๋าปลายทาง พร้อมสลับกระเป๋าให้อัตโนมัติหากมีการเลือกตรงกัน
  - **Responsive UI:** ป้องกันการล้นจอ (Right Overflow) ด้วย `isExpanded: true` และการตัดคำแบบ Ellipsis
- **ประวัติและการค้นหา (History & Filter):** แสดงรายการย้อนหลังแบ่งตามวันพร้อมเว้นระยะห่าง 10px ดูสบายตา ค้นหาจากข้อความใน Note หรือกรองข้อมูลตามหมวดหมู่ กระเป๋าเงิน และช่วงเวลาได้

## 2. ระบบรายการประจำอัตโนมัติ (Recurring Transactions)
- **ตั้งค่ารายการเกิดซ้ำ:** สร้างแม่แบบรายการที่ต้องจ่ายหรือรับเป็นประจำ เช่น ค่าอินเทอร์เน็ต, ค่าหอพัก, ค่าบริการสตรีมมิง หรือเงินเดือน
- **กำหนดรอบความถี่:** เลือกรอบการเกิดซ้ำได้แบบ รายวัน, รายสัปดาห์, รายเดือน หรือรายปี พร้อมกำหนดวันเริ่มต้นและวันสิ้นสุด
- **การทำงานอัตโนมัติ (Auto-Execute & Notification):**
  - เมื่อเปิดแอป ระบบจะตรวจสอบวันที่ปัจจุบันเทียบกับ `next_due_date` ในฐานข้อมูล หากถึงกำหนดจะสร้างรายการธุรกรรมลงตารางหลักให้อัตโนมัติทันที
  - ตั้งค่า Local Notification เพื่อแจ้งเตือนล่วงหน้าหรือแจ้งเตือนเมื่อถึงวันครบกำหนดชำระ

## 3. ระบบจัดการกระเป๋าเงินและหมวดหมู่ (Wallets & Categories)
- **จัดการหลายกระเป๋าเงิน (Multi-Wallets):** สร้างกระเป๋าแยกตามประเภทการใช้งาน เช่น เงินสด, บัญชีธนาคาร, บัตรเครดิต พร้อมกำหนดยอดเงินตั้งต้น (Initial Balance) สี และไอคอน
- **คำนวณยอดคงเหลืออัตโนมัติ:** แสดงยอดเงินคงเหลือสุทธิของแต่ละกระเป๋าและยอดรวมทั้งหมดแบบ Real-time จากประวัติธุรกรรม
- **หมวดหมู่เริ่มต้นและปรับแต่งเอง (Custom Categories):** มีข้อมูลหมวดหมู่พื้นฐานมาให้พร้อมใช้ (Seed Data) และผู้ใช้สามารถเพิ่ม/แก้ไขชื่อ สี และไอคอนของหมวดหมู่รายรับ-รายจ่ายได้เอง

## 4. แดชบอร์ดและรายงานสรุปผล (Analytics & Reports)
- **การ์ดสรุปภาพรวม (Overview Card):** แสดงยอดรายรับรวม รายจ่ายรวม และเงินคงเหลือสุทธิประจำเดือน พร้อมโลโก้แบรนด์ "จดตัง" ในการ์ดยอดเงินรวม
- **กราฟสัดส่วน (Visual Charts):** แสดง Pie Chart / Donut Chart เปรียบเทียบสัดส่วนรายจ่ายแยกตามหมวดหมู่ พร้อมคำนวณเปอร์เซ็นต์เพื่อให้เห็นพฤติกรรมการใช้จ่ายชัดเจน

## 5. ระบบความปลอดภัยและล็อกแอป (Security & App Lock)
- **ล็อกด้วยรหัส PIN 4 หลัก (PIN Lock):** ตั้งรหัสผ่านตัวเลข 4 หลัก สำหรับยืนยันตัวตนก่อนเข้าใช้งานแอป (จัดเก็บรหัสผ่านที่เข้ารหัสแฮช SHA-256 ไว้ใน Secure Storage ปลอดภัย 100%)
- **แป้นพิมพ์สัมผัสไว (Responsive Keypad):** ใช้คอมโพเนนต์ `_KeypadCell` ที่แยกเลเยอร์สัมผัส ตอบสนองการแตะทันที ไม่มีอาการกดไม่ติด
- **ล็อกอัตโนมัติเมื่อสลับแอป:** ตรวจสอบสถานะแอป (`AppLifecycleState`) เพื่อบังคับให้ใส่รหัสใหม่เมื่อพับจอหรือสลับไปแอปอื่น

## 6. ระบบส่งออกและสำรองข้อมูล (Export, Backup & Restore)
- **Export เป็นไฟล์ CSV (รองรับ Excel):** ส่งออกประวัติธุรกรรมตามช่วงวันที่เลือกเป็นไฟล์ `.csv` (เข้ารหัส UTF-8 BOM รองรับภาษาไทย 100%) สำหรับนำไปเปิดใน Excel หรือ Google Sheets
- **Full Backup & Restore (รองรับไฟล์ฐานข้อมูล + รูปสลิป):**
  - **การสำรองข้อมูล (Backup):** รวบรวมไฟล์ฐานข้อมูล `.db` และโฟลเดอร์รูปภาพสลิปทั้งหมดบีบอัดเป็นไฟล์ `.zip` ก้อนเดียว เพื่อส่งออกไปยังที่เก็บไฟล์ในเครื่องหรือแชร์ภายนอก
  - **การกู้คืนข้อมูล (Restore):** เลือกไฟล์ `.zip` (หรือ `.db`) เพื่อแตกไฟล์นำฐานข้อมูลและรูปภาพสลิปทั้งหมดกลับคืนสู่แอปได้อย่างสมบูรณ์
- **ล้างข้อมูลทั้งหมด (Reset Data):** ลบประวัติธุรกรรมและไฟล์รูปภาพสลิปในเครื่องเพื่อเริ่มต้นใหม่

## 7. ธีมและประสิทธิภาพของระบบ (Theme & Performance)
- **Light / Dark Mode:** รองรับการเปิด-ปิดสลับโหมดสว่าง/โหมดมืดได้จากหน้าการตั้งค่า ผ่าน `ThemeController`
- **Performance Optimization:** ปรับปรุงความลื่นไหลระดับ 60 FPS ปิดการเรนเดอร์ Blur หนัก ๆ แบบซ้อนทับในรายการและพื้นหลัง ลดการกินทรัพยากรเครื่องและแบตเตอรี่

## 🛠️ แพ็กเกจ Flutter ที่ใช้รองรับฟีเจอร์ทั้งหมด

| ฟีเจอร์ | แพ็กเกจที่ใช้ | หน้าที่หลัก |
| :--- | :--- | :--- |
| **ฐานข้อมูลหลัก** | `sqflite`, `path`, `path_provider` | จัดการฐานข้อมูล SQLite และเข้าถึงโฟลเดอร์เก็บไฟล์ภายในเครื่อง |
| **แนบรูปสลิป** | `image_picker`, `flutter_image_compress` | ถ่ายรูป/เลือกรูปสลิป และบีบอัดขนาดไฟล์รูปก่อนเซฟลงเครื่อง |
| **ล็อกแอป (Security)** | `flutter_secure_storage`, `crypto` | จัดการรหัส PIN แฮช SHA-256 ใน Hardware-backed Keystore |
| **รายการประจำ & แจ้งเตือน** | `flutter_local_notifications` | แจ้งเตือนเมื่อถึงกำหนดจ่ายบิลหรือเตือนให้จดบัญชีประจำวัน |
| **Export & Backup** | `csv`, `archive`, `share_plus`, `file_picker` | สร้างไฟล์ CSV, บีบอัดไฟล์ `.db` คู่กับรูปสลิปเป็น `.zip` และแชร์/นำเข้าไฟล์ |
| **กราฟและแสดงผล** | `fl_chart`, `intl` | วาดกราฟสรุปผลรายจ่าย และจัดรูปแบบวันที่/สกุลเงิน |
| **การจัดการธีม** | `shared_preferences` | บันทึกสถานะการตั้งค่า Light / Dark Mode |
